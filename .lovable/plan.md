

## 피어 랭킹 개선: 상위 10명 + 나 & 사용자 수 펌핑

### 요약
교재별 피어 랭킹을 **상위 10명 + 나**로 제한하고, `user_count_offset` 컬럼을 추가하여 **80~120명** 범위에서 교재별 사용자 수를 부풀려 표시합니다.

### 작업 단계

**1. DB 마이그레이션** — `books` 테이블에 `user_count_offset` (integer, default 0) 컬럼 추가

**2. 교재별 오프셋 데이터 설정** (insert tool)

| 교재 | offset |
|------|--------|
| 재무관리연습 8판 | 95 |
| IFRS 중급회계연습 | 120 |
| IFRS 고급회계연습 | 85 |
| CPA 2차 최적서 원가관리회계 | 90 |
| 세무회계연습(법인세법) / 이승철 | 110 |
| 세무회계연습(법인세법) / 강경태 | 105 |
| 세무회계연습(법인세법) / 정우승 | 88 |
| 세무회계연습(법인세법) / 주민규 | 92 |
| 세무회계연습(소득세법·부가세법·상증세법) / 이승철 | 100 |
| 세무회계연습(소득세법·부가세법·상증세법) / 강경태 | 98 |
| 세무회계연습(소득세법·부가세법·상증세법) / 정우승 | 82 |
| 세무회계연습(소득세법·부가세법·상증세법) / 주민규 | 87 |

**3. 프론트엔드 수정**

- **`useSocialFeed.ts`**: peers `.slice(0, 10)` 유지, 내가 10등 밖이면 별도 추가. `BookFeedItem`에 `totalPeerCount` 추가 (실제 user_books 수 + offset)
- **`LiveFeed.tsx`**: 
  - 상위 10명 표시, 내가 10등 밖이면 `···` 구분선 + 내 순위 행
  - 하단에 `"{totalPeerCount}명이 풀고 있어요"` 라벨 표시

### 기술 상세

```text
피어 랭킹 표시:
  1등  👑 user_a   ████████ 45문제
  2등     user_b   ██████   32문제
  ...
  10등    user_j   ██       8문제
  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ (내가 10등 밖일 때만)
  23등    나       █        3문제  상위 X%
  ──────────────────────────
  "127명이 풀고 있어요"
```
