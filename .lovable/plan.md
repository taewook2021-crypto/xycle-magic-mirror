

## 소셜 관음 기능 강화

현재 피드는 숫자 나열일 뿐, "저 사람 뭐하고 있지?" 하고 들여다보고 싶은 욕구를 전혀 자극하지 못함. 스트라바가 중독적인 이유는 **남의 활동을 구체적으로 엿볼 수 있기 때문**.

### 추가할 기능

**1. 실시간 활동 스트림 (Activity Timeline)**
- 피드 상단에 "지금 공부 중" 섹션: 최근 10분 내 풀이 기록이 있는 유저 표시
- 녹색 점 + "김O현 — 세법개론 풀이 중 (3분 전)"
- 시간이 지나면 "김O현이 세법개론 12문제 완료" 형태로 전환

**2. 피어 프로필 카드 (클릭 시 Sheet/모달)**
- 피드에서 닉네임 클릭 → 슬라이드업 시트로 해당 유저 정보 표시
- 내용: 오늘 풀이량, 이번 주 풀이량, 연속 학습일, 교재별 진도율 바
- `is_public=true`인 유저만 상세 표시, `false`면 "비공개 프로필" 안내
- "회독표 보기" 버튼 → 해당 유저의 회독 그리드를 읽기 전용으로 열람

**3. 오늘의 랭킹 강화**
- 현재: 교재별 순위 리스트만 있음
- 변경: 각 피어 옆에 **프로그레스 바** 추가 (1위 대비 비율)
- 내 순위에 하이라이트 + "상위 N%" 배지
- 1위에 👑, 연속 1위 시 "3일 연속 1위" 태그

**4. 학습 히트맵 (GitHub 잔디 스타일)**
- 피어 프로필 시트 안에 최근 30일 히트맵 표시
- 날짜별 풀이량에 따라 색 농도 변화
- 내 프로필에서도 동일하게 표시 → 비교 욕구 자극
