

## '재무관리연습 11판 / 김민환' 교재 추가

### 개요
3개의 PDF(예제 96문항, 필수 290문항, 보충 48문항)에서 추출한 데이터를 기반으로, 재무관리 과목에 김민환 교재를 추가합니다. 총 434문항, 16개 챕터.

### 구현

**SQL 마이그레이션 1건** -- `books`, `chapters`, `questions` 테이블에 INSERT:

- **books**: `subject_id = 'a1000000-0000-0000-0000-000000000001'` (재무관리), title = '재무관리연습 11판', author = '김민환', display_order = 2
- **chapters**: 16개 챕터 (chapter_number 1~16)
- **questions**: 434문항, 각 챕터별 순차 번호 1부터 (예제 → 필수 → 보충 순서)
- `filter_config`: `{"show_type_filters": false, "show_star_filter": false}` (기존 연습서와 동일)
- 모든 question_type = 'example', is_essential = false

코드 변경은 없습니다. 기존 시스템이 자동으로 새 교재를 인식합니다.
