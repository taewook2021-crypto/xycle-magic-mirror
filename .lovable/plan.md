

## 전체 서비스 흐름 설계

### 데이터 흐름 요약

```text
[개발자(우리)]                         [학생(이용자)]
    │                                      │
    ├─ 교재 데이터 대화창에 복붙 ──┐          │
    │                            ▼          │
    │                     SQL 변환 후        │
    │                     Supabase에 삽입    │
    │                            │          │
    │   subjects ◄───────────────┤          │
    │   books ◄──────────────────┤          │
    │   chapters ◄───────────────┤          │
    │   questions ◄──────────────┘          │
    │                                      │
    │                            로그인 ────┤
    │                                      ▼
    │                            교재 선택/구독
    │                            (내 교재 목록에 추가)
    │                                      │
    │                              ┌───────┴───────┐
    │                              ▼               ▼
    │                           회독표           채점 입력
    │                         (O/X/△ 기록)    (답안 입력→자동채점)
    │                              │               │
    │                              └───────┬───────┘
    │                                      ▼
    │                                  attempts 저장
    │                                      │
    │                                      ▼
    │                                  대시보드/분석
```

---

### 1단계: 데이터 등록 (개발자 작업)

- 교재 정보를 대화창에 텍스트로 복붙
- 형식 예시: `교재명 | 저자 | 챕터1(문항수) | 챕터2(문항수) | ...`
- Lovable이 SQL INSERT문으로 변환 → Supabase에 직접 삽입
- **학생은 등록 기능 없음** — 읽기 전용

---

### 2단계: 학생 사용 흐름

```text
로그인 → 교재 목록 조회 → "내 교재"에 추가(구독)
                              │
         ┌────────────────────┼────────────────────┐
         ▼                    ▼                    ▼
      회독표               채점 입력            대시보드
```

**교재 구독**: `user_books` 테이블 (user_id, book_id) — 학생이 사용할 교재만 선택

---

### 3단계: 채점/입력 모드 (3가지)

| 모드 | 대상 | 동작 |
|------|------|------|
| **빠른 채점** | 객관식 | 챕터 선택 → 문항별 1~5번 클릭 → 정답 자동 비교 → O/X 저장 |
| **범위 모드** | 객관식/주관식 | 시작~끝 문항 설정 → 틀린 문항만 X 체크 → 나머지 자동 O → X 재클릭 시 △ 전환 |
| **실시간 모드** | 전체 | 회독표에서 셀 직접 클릭하여 O/X/△ 입력 |

---

### 4단계: 회독표 표시

- 교재 선택 → 챕터별 문항 × 회차 격자
- attempts 테이블에서 해당 교재의 기록 조회
- 같은 챕터를 다시 풀면 새 회차로 자동 분류
- 색상 히트맵: O=연초록, X=빨강, △=노랑

---

### DB 테이블 구조 (필요한 것만)

```text
subjects          과목 (중급회계, 세법 등)
books             교재 (subject_id FK)
chapters          챕터 (book_id FK)
questions         문항 (chapter_id FK, correct_answer)
user_books        학생 교재 구독 (user_id, book_id)  ← 신규
attempts          풀이 기록 (user_id, question_id, result, round)
user_roles        역할 (admin/student)
profiles          프로필 (exam_type, display_name)
```

4. 회독표 DB 연동 (books → chapters → questions → attempts 조회)
5. 채점 입력 페이지 (빠른채점 + 범위 모드)
