

## 분개장 메모 모아보기 개선 계획

### 1. 인라인 확장 (페이지 이동 → 토글)
- `Profile.tsx`의 메모 카드에서 클릭 시 `navigate()` 동작 제거
- `expandedMemoId` 상태로 단일 확장 관리 (한 번에 하나만 펼침)
- **접힌 상태**: 기존처럼 교재명 · 챕터/문항 + 메모 1줄 미리보기
- **펼친 상태**: 메모 전체 내용 + 하단 액션 영역
  - `[회독표에서 보기]` 버튼 → 해당 교재의 해당 문항으로 이동
  - `[삭제]` 버튼 (기존 유지)
- 부드러운 펼침 애니메이션 (height transition)
- 긴 메모는 `max-h-60 + overflow-auto`

### 2. 과목별 필터 칩
- 메모 데이터를 questions → chapters → books → subjects 조인으로 과목 정보 확보
- 메모 섹션 상단에 가로 스크롤 가능한 칩 행 추가
  - `[전체 N] [중급회계 12] [고급회계 5] [재무관리 3] ...`
  - 메모가 1개 이상 있는 과목만 노출
- 칩 선택 시 해당 과목 메모만 필터링 (클라이언트 사이드)
- 선택된 칩은 primary 색상 강조

### 3. 변경 파일
- `src/pages/Profile.tsx` — 메모 섹션 로직/UI 수정
- (필요 시) 메모 fetch 쿼리에 subject 정보 join 추가

### UX 디테일
- 칩과 메모 카드 모두 기존 디자인 시스템 토큰 사용 (Badge / Button / Card)
- 모바일 우선: 칩 가로 스크롤, 카드 풀폭
